Categories
Header (Mull pattern): back, page name, info, overflow only when there are secondary actions. No home button, no page description, no header add button. The primary create action is an extended FAB at the bottom centre (56, radius 16, primaryContainer, icon + label, 24 from the bottom, content fades under it). The header "Add Category/Group" action splits: Add Category is the FAB, Add Group moves to the overflow. Each group is a section header (with its own more menu: Edit / Delete group) over one grouped list.
