Why the fidelity variant

Signature · tonalSpot (Flutter default)
primary #445E91
container #D8E2FF
Squeakdin · tonalSpot
primary #4C5C92
container #DCE1FF
Signature · fidelity
primary #0058BE
container #2170E4
Squeakdin · fidelity
primary #00236F
container #1E3A8A
ColorScheme.fromSeed(seedColor: seed, brightness: b, dynamicSchemeVariant: DynamicSchemeVariant.fidelity) With the default tonalSpot variant, Kuber Signature and Squeakdin Navy collapse into the same muted blue (chroma is capped at 36). Fidelity keeps each seed's own chroma, so all 7 stay distinct and recognisable. Squeakdin seed moves from #4A7FD1 to #1E3A8A (its Alabaster primary) so it reads as navy, not a second blue. Obsidian override: surface and surfaceContainerLowest = #000000 (true black, as today). Every other role comes from the scheme untouched.
