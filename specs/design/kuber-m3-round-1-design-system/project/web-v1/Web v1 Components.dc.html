Web v1 · Components

Website components in Kuber Signature light and dark, built on the app M3 tokens (tokens.md). Every colour is a CSS custom property, so all sixteen themes recolor these without new designs.

C1

Floating nav

Pill: surface, 1px outlineVariant, radius full, height 56 (padding 8), items 40 high, 16 side padding, labelLarge. Active item: secondaryContainer + onSecondaryContainer, aria-current="page". Inactive: onSurfaceVariant, hover 8% onSurface state layer, focus 3px primary ring with 2px offset. Theme button sits after a divider and stays secondary. FAB is 10 to the right of the pill, as in the app. Scrolled (after 24px): top 16 to 8, pill 56 to 48 on surfaceContainer, items 36, FAB 56 to 48. Tablet: wordmark hidden, icon-only FAB. Mobile: logo, theme, menu.

App mockup frame
