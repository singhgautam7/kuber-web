Automatic Backups

States
One status card on top answers "am I safe?" in tone: secondaryContainer when never set up, income container when on or backed up, error container on failure with the fix (Choose new folder) inside it. The master switch and its settings live in one grouped list, so turning it off collapses the settings in place. Frequency and Keep last are segmented buttons (Daily / Weekly / Monthly, 1 / 5 / 10). The helper line under Backup now explains why it is disabled. Proposed: next run + folder chips on the status card, and a Saved backups list read from the folder (retention made visible).
