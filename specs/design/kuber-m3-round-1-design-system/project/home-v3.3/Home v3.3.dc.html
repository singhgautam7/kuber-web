Kuber · Home v3.3

Home v3.3 · How Kuber works, merged into Welcome

The 5-page tour is now the Welcome flow, and stays in More with Try it buttons. Existing users get a one-time Home card. No pricing language anywhere. Built on Home v3.2; where they differ, Home v3.3 wins. Shown in Signature light and dark, plus all 7 themes on HV33.5. Specs next to this file: flow.md, entry-points.md, storyboards.md, copy.md, changelog.md, open-decisions.md.

HV33.1

Home v3.3 · Welcome flow

Make it yours (language, currency, name, theme) opens Welcome and carries the brand row (logo, Kuber). Then What do you want to track?, then the 5 tour pages, then Home. From W2 on, Skip is always in the same top-right place: on W2 it moves on to tour page 1, on W3 to W7 it opens Home. No Try it inside Welcome. Every frame is a rest frame. Order and rules in flow.md.
