# Home v3.3 · changelog (differences from Home v3.2)

Every change from Home v3.2. Earlier folders are not edited; where v3.3 conflicts with them, **v3.3 wins**.

Unchanged: bottom nav; Make it yours fields; What do you want to track? chips and Continue; Get started; suggestions; M3 tokens, components and motion tokens; v3.2 animation rules (once, rest frame, built-ins only, reduced-motion static frame, shared sample data, theme roles only).

## Flow and entry points

**V33-01 · Tour merged into Welcome**
- v3.2: Welcome → Purpose → Make it yours → tracking question (with a "How Kuber works" button) → optional tour → Home.
- v3.3: Make it yours → tracking question → tour pages 1 to 5 → Home. 7 dots. Skip is always visible after Make it yours. Spec: flow.md. Board HV33.1.

**V33-02 · Page 1 absorbs the Welcome page**
- The old first Welcome page and the v3.1 Purpose page are gone. The brand row (logo, "Kuber") moves to Make it yours, now the first screen. Tour page 1 keeps the habit message. See open-decisions 1 for the offline and no-signup facts.

**V33-03 · Skip after Make it yours**
- v3.2: Skip from the intro pages returned to the tracking page and skipped Make it yours. v3.3: no Skip on Make it yours; Skip on the tracking question moves on to the tour; Skip on all 5 tour pages opens Home.

**V33-04 · No Try it in Welcome**
- Page 5 in Welcome reads Start using Kuber (`homeV33_tourFinish`) and opens Home. `homeV32_tourStart` retired.

**V33-05 · "How Kuber works" button removed from the tracking question**

**V33-06 · More: Why Kuber? replaces Welcome Tour and How Kuber works**
- v3.2: Welcome Tour and How Kuber works rows. v3.3: one row, Why Kuber?, subtitle "How expense tracking works, and how Kuber helps", in Welcome Tour's place. The Home card uses the same title. Try it on every page, Done on page 5. Open-decisions 4.

**V33-07 · Home card for existing users only, once**
- v3.2: new users (top slot, after Get started) and existing users, up to 5 days. v3.3: only users onboarded before this update, first launch after it, under the greeting on every layout, one session. Spec: entry-points.md › c. Board HV33.3.

**V33-08 · Top slot order restored**
- v3.2: Get started > promo > tour card > suggestion. v3.3: Get started > promo > suggestion.

## Pricing

**V33-09 · "Free to try" removed everywhere**
- Removed from the page 5 subhead and the Ask Kuber, Kuber Cards and Kuber Notes tiles. No free, Pro, limits or prices on any page or entry point. The copy generator fails the build if those words appear.

## Pages

**V33-10 · Page 1 rewritten: Why Kuber exists**
- v3.2: "Note every expense. See where it goes." with SMS or Quick Add → transaction → account and category.
- v3.3: "Make noting every expense a habit." Notebook with Date, Amount, Spent on, Category; a pen writes 3 rows; rows lift into transaction cards. Subhead mentions bank SMS for INR only. No handwriting font (0 bytes added).

**V33-11 · Page 2 rewritten: Every account, every category**
- v3.2: "Everything lands in place." (expenses dropping into accounts). v3.3: "Every account. Even credit cards." Bank, cash and credit card with balance or due, the card's billing cycle and due date (`billGenerationDay`, `paymentDueDay`), and a new Pet care category.

**V33-12 · Page 3 rewritten: Track more than spending**
- v3.2: "Nothing due slips by." (timeline + budget). v3.3: five modules with live visuals: budget bar, SIP line, EMI ring, lent and borrowed, subscription renewal. Only supported types named (SIPs, stocks, FDs; home loan).

**V33-13 · Page 4: new subhead and animation**
- Headline kept. Subhead "Every transaction in one searchable history, with many ways to analyze it." Animation: History scroll, search narrows to food, then By category, Monthly, Compare, resting on three minis.

**V33-14 · Page 5: one line per feature, spotlight**
- Headline kept. Subhead replaced by 5 lines (Ask Kuber, Kuber Cards, Kuber Notes, Calculators and tools, Reminders). Reminders added. Spotlight runs through them with the matching line highlighted. 2 × 2 tile grid removed.

**V33-15 · Durations**
- v3.2: 1880 to 3190 ms. v3.3: 2740 to 3900 ms (within the 2 to 4 s rule).

**V33-16 · Purpose screen and Quick Add demo retired**
- The v3.1 Purpose screen no longer exists, so V32-06 and V32-07 no longer apply. Non-INR handling is now just the subhead and amount format on page 1.
