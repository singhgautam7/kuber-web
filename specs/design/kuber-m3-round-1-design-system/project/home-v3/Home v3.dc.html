Kuber · Home v3

Home v3 · a quieter first run

Built on Home v2; where they differ, Home v3 wins. Day 1 is the Get started card alone. One optional welcome question turns on widgets for what the user tracks. After the first SMS import Kuber offers to add the banks it found. Widgets join Home quietly as data arrives. Existing users keep today's Home. Every difference from v2 is listed in changelog.md; specs: widget-inventory.md, suggestion-rules.md, copy.md, open-decisions.md.

HV3.1

Home v3 · Screens

Six Home v3 moments for a new install, then the existing-user Home for reference (unchanged, same builder as Screen 2 - Home, cropped to its first 1240px). Day 1 shows only Get started. Widgets join quietly as data arrives: no labels, no celebration. Recent transactions is no longer on Home; it lives in the History tab. The bottom nav is unchanged.

Alabaster · Signature
Skipping the welcome question gives the Get started card alone. Picking choices turns on their widgets in empty state. The first SMS import adds transactions, so Balance Card and Income and Expense turn on, and the accounts prompt offers the banks it found. By day 3 Money Stories and the new accounts are on. After graduation the top slot holds one suggestion, and SMS Import and Quick Add join Home for good.
