Kuber · Home v2

Home v2 · a simpler first-run Home

New installs start with 3 widgets and a Get started card. Widgets that need data turn on when the data exists. After setup, one suggestion at a time comes from the user's own transactions. Existing users keep today's Home. Built on the Kuber M3 tokens and components; specs live next to this file: widget-inventory.md, suggestion-rules.md, copy.md, open-decisions.md.

HV2.1

Home v2 · Screens

Four Home v2 moments for a new install, then the existing-user Home for reference. Existing users keep today's Home exactly: the right-most phone is rendered by the same builder as Screen 2 - Home. Home v2 phones are drawn at full scroll length; the existing-user reference is cropped to its first 1240px.

HV2.7

Home v2 · Finding hidden widgets

Home already has customization: the Edit widgets button at the bottom of Home opens Edit Home Widgets. Home v2 keeps both, adds a count line under the button, and groups the editor so waiting widgets are visible and can be turned on early.

Bottom of Home and the editor
Switch on: shows now, with its normal empty state. Switch off on any widget: stays off, never turns on by itself. A waiting widget that turns on by itself moves to "On your Home". Suggestions is the first row with a pin instead of a drag handle: it cannot be reordered, always renders in the top slot, and its switch is the same setting as Settings › Suggestions on Home (changing either updates both). It appears in the editor once Get started has graduated. Save changes keeps today's behaviour (disabled until something changes). Existing users see today's editor unchanged.
